# Homework 05 — Information Architecture and User Flow
## Project: Exotic Pet Keeper

For this homework, I designed the information architecture and main user flow for recording a feeding event and retrieving it from an animal's feeding history.

## Completed Work

The FigJam board includes:

- A prioritized content inventory of 15 elements.
- Three simulated card sorting exercises and a summary of provisional findings.
- A sitemap showing the screen hierarchy, entry points, and shortest path to the main task.
- Six main screens with their supported functions.
- A user flow with three exceptional situations: no registered animals, invalid feeding details, and save failure.
- Four selected screens for Homework 6 wireframes.

## Research Limitation

The three card sorting participants were fictional simulations. The findings and label decisions are provisional and have not been validated with real participants.
