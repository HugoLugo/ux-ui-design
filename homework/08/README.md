# Homework 08 — Usability Testing and Mini UI Guideline

## Project: Exotic Pet Keeper

### Updated Prototype

[Open the Homework 8 prototype](https://www.figma.com/proto/LqJRKvQKSnCPGnXdbsarWf/Exotic-Pet-Keeper-%E2%80%94-Homework-6-Wireframes?node-id=50-68&page-id=0%3A1&starting-point-node-id=50%3A68)

### Deliverables

The Figma file includes:
- Usability test plan and consent briefing.
- Three clearly labeled simulated participant walkthroughs.
- Observations, quotations, interpretations and severity-ranked hypothetical findings.
- Refined feeding screens with improved instructions and error messages.
- Mini UI guideline with semantic color variables, light/dark modes, text styles, spacing, and component rules.
- Documented WCAG AA contrast checks.

### Design Improvements

The refined interface uses consistent semantic colors and typography. Error messages include text rather than relying solely on color, and the feeding flow provides clearer guidance.

### Reflection

The simulated exercise highlighted potential confusion around non-editable form fields. Future improvements should support real data entry and be evaluated with actual users.

### Research Limitation

All three participant walkthroughs are fictional simulations, not empirical usability tests. The assignment's requirement for three real participants remains unmet.
