## Project Overview

Exotic Pet Keeper is a UX/UI project focused on helping keepers maintain and retrieve individual animals' care records.

The selected task is recording a feeding event and finding that record later.

**Main claim:** Animal care records are useful only when they can be retrieved easily.

## Prototype Demonstration

The main task follows this journey:

Dashboard → Quick Feeding → Sample Selected → Feeding Saved → Feeding History → Feeding Record Details.

The prototype also demonstrates validation errors and recovery.

Four key screens are included in the presentation as a backup for the live demonstration.

## Results and Evidence

**Success criterion:** The user reaches the selected animal's saved feeding record and verifies its details.

**Technical verification:**

- The main prototype navigation and error path were checked.
- All nine expected Homework 9 navigation links were verified.
- A shared component-radius variable was modified from 8 px to 10 px.
- All seven inspected component and instance nodes updated automatically.

**Research limitation:** Earlier participant walkthroughs were fictional simulations. No independent participant success rate, completion time, or before-and-after usability improvement was measured.

## Self-Reflection

**Strongest evidence:** The verified prototype navigation and shared component behavior demonstrate that the interface is technically consistent and supports the intended task flow.

**What I learned:** A visually understandable interface is not necessarily an empirically validated interface. Prototype interactions can also create expectations that differ from actual application functionality.

**What I would investigate further:** Whether first-time users understand the feeding form, validation messages, and history navigation without assistance.

**Next step:** Conduct three real, unassisted usability tests, recording task completion, time, navigation mistakes, and help requests. Use the findings to refine the interactions.
