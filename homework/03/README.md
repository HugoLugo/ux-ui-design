# Homework 03 — Usability and Accessibility Audit

For this homework, I conducted a usability and accessibility audit of Reptile Scan, a reptile management application.

The examined task was registering a reptile, recording a feeding event, and retrieving its feeding history.

## Audit Results

The audit includes six annotated findings:

- **A1:** Low-contrast table headers.
- **A2:** Non-descriptive Add Feeding link.
- **U1:** Difficulty discovering feeding history.
- **U2:** Missing Cancel or Back button in the feeding form.
- **U3:** Unnecessary email display in feeding records.
- **U4:** Ambiguous feeding form labels.

Each finding includes its observation, relevant usability or accessibility principle, user consequence, improvement direction, and severity.

The accessibility assessment included contrast measurements, keyboard navigation, and responsive checks. The Add Feeding link was also examined through its HTML structure as a potential accessibility barrier.
