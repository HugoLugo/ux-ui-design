# Homework 04 — Problem Definition and Opportunity Search

## Project: Exotic Pet Keeper

For this homework, I defined the main problem and explored possible solutions for recording and retrieving animal feeding information.

The FigJam board includes:

- A project brief and stakeholder table.
- A user story and research-based problem statement.
- Three How Might We questions.
- Eight brainstorming ideas and dot voting.
- A 2×2 Impact vs. Feasibility Matrix.
- A chosen direction with justification.
- Clearly identified research evidence and unverified assumptions.

**Chosen direction:** A simple feeding workflow combining Quick Feeding, a clearly labeled View History button, and Save Confirmation.
