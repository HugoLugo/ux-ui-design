# Homework 06 — Low-Fidelity Wireframes

## Project: Exotic Pet Keeper

This homework presents low-fidelity wireframes for recording an individual animal's feeding event and retrieving the saved record from its feeding history.

## Completed Work

The Figma file includes:

- Five main mobile screens: Dashboard, Quick Feeding, Save Confirmation, Feeding History, and Feeding Record Details.
- Two critical states: invalid feeding form and no registered animals.
- A larger-screen responsive Dashboard.
- Editable interface elements with descriptive layer names and Auto Layout.
- Navigation references, assumptions, and annotations on the Notes page.

## Layout and Design Decisions

The mobile screens use a single-column layout, while the larger Dashboard arranges the main actions side by side.

Quick Feeding is the primary action. Viewing animal records is secondary. After saving, View History guides the user toward retrieving the recorded information.

All wireframes use only three neutral tones, without final colors, photographs, or decorative icons.

The example animal and feeding records are fictional wireframe content.
